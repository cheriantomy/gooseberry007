## What it does
- Browse AI models and agents in one place
- Compare models side by side on performance metrics
- Read reviews and find the right fit for your use case
- Deploy guidance for the models you choose

## AI Services
| Service | What it does | Who it's for |
|---|---|---|
| Model Discovery | Search and filter AI models | Developers, researchers |
| Model Comparison | Compare performance metrics | Teams choosing a model |
| Agents Directory | Explore AI agents | Builders, businesses |
| Deployment Guides | Steps to deploy a model | Engineers 

## Key insights
• Developed a demo AI voice agent as a secondary upsell option, using prompt engineering in Lovable, API keys,
and LLM orchestration with ChatGPT and ElevenLabs, and tested its integration with Google Calendar.
• Conducted User Acceptance Testing on the AI voice agent to assess whether it achieved a success rate of
around 50–80% across consumer-facing functionality, including latency, interpretation, and accuracy.
